## 阶段 2：核心规则引擎 🔲

### 2.1 数据层
| 任务 | 优先 | 说明 |

| 任务 | 优先 | 说明 |

| AP 系统 | P0 | 按回合数自动管理AP卡数量 |

| 游戏初始化流程 | P0 | Shuffle → Draw → Mulligan → Life Setup |

### 2.3 回合/阶段状态机
| 任务 | 优先 | 说明 |
|------|------|------|

### 2.4 使用卡牌系统
| 任务 | 优先 | 说明 |
|------|------|------|

| 使用Event卡 | P0 | 能量检查→AP支付→效果结算→Sideline |

### 2.5 能力结算引擎（核心难点）
| 任务 | 优先 | 说明 |
|------|------|------|
| 能力数据结构 | P0 | Timing + Condition + Cost + Effect 模型 |
| 时机触发器 | P0 | 注册/触发/排序能力（按规则：回合玩家优先） |
| 条件评估器 | P0 | 运行时检查条件是否满足 |
| 代价支付器 | P0 | 原子支付（全部满足才支付） |
| 效果执行器 | P0 | 6大类效果（移动/BP/状态/关键词/伤害/搜索） |
| 目标选择器 | P0 | 解析目标描述符 → 合法目标列表 |
| 同时发动队列 | P0 | 玩家自选顺序 + 对方能力后结算 + 新能力插入 |
| 关键词展开器 | P0 | 9种关键词 → 等效能力条目 |
| Once Per Turn 追踪 | P1 | 每张卡每回合的能力使用记录 |
| 持续性效果管理 | P1 | Duration追踪 + 到期自动清除 |
| 替代效果 ({x} instead) | P2 | 条件判断 → 文本替换 |
